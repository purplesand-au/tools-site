# tools-site

Landing page for `tools.purplesand.com.au`.

## Contents

- `index.html` — landing page. Points clients without a direct tool URL back to their account manager.
- `assets/img/purplesand-logo.png` — Purple Sand logo, used in the header and footer disclaimer.

## Theme

Matches the Purple Sand brand theme used across project sites (e.g. `website/`), copied from `IMG_Two_Options_Financing_Proposal.html`:

- `--purple: #5B2C83`, `--purple-dark: #3D1D5A`, `--purple-light: #9B6FC4`
- `--sand: #C9A876`
- `--charcoal: #2B2B2E`, `--grey: #6B6B70`, `--lightgrey: #F2F0F5`
- Header: purple gradient background, logo on white pill, sand-colored uppercase tag
- Body font: `-apple-system, "Segoe UI", Calibri, Arial, sans-serif`

## Disclaimer

Footer includes the standard Purple Sand Pty Ltd IP disclaimer (same wording used in client-facing proposal tools) alongside the logo.
